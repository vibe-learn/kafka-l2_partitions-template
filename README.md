        # kafka — Партиции и параллелизм

        Homework template for the Vibe Learn lesson **l2_partitions** (Партиции и параллелизм).

        ## Task

        Напиши Go-программу, которая запускает локальный Kafka через Docker Compose, создаёт топик
с 3 партициями, затем отправляет 100 сообщений с ключами user_0 … user_4 (key = "user_" + strconv.Itoa(i % 5)).
Консьюмер собирает для каждого ключа множество партиций, в которых были получены его сообщения.
CI-проверки: (1) все сообщения с одинаковым ключом получены из одной и той же партиции;
(2) 5 уникальных ключей распределились максимум по 3 партициям (≤ partition_count).

        ## How to work

        1. The Vibe Learn platform creates a copy of this repo in your GitHub account when you click «Начать домашку» on the lesson.
        2. Clone it locally, complete the TODOs in `main.go`, and push.
        3. CI (`.github/workflows/ci.yml`) runs the tests on every push. The Vibe Learn platform listens to the result via webhook and unlocks the lesson when CI passes.

        ## Local prerequisites

        - Go 1.22+
        - Docker + docker-compose (for the local Kafka cluster, when the lesson requires it)

        ## Running

        ```bash
        go test ./...
        ```
